# X-LABO 代理店管理アプリ（プロトタイプ）

退職サポートプラス 代理店管理アプリ（`taishoku-agency-daiten`）の仕様をベースに、
X-LABO のポイント制度へ作り替えた初期リリース設計プロトタイプです。

## 起動

```
npm install
npm run dev
```

→ http://localhost:3360

ダブルクリックで起動したい場合は、**Mac は `dev-launch.command`／Windows は `dev-launch.cmd`**。
（Mac で初回だけ「開けません」と出たら `chmod +x dev-launch.command` を一度実行）

Mac に Node.js が入っていない場合は先に `brew install node`（または https://nodejs.org/ja から LTS版）。
手順の詳細は [`Mac移行手順.md`](./Mac移行手順.md) にまとめています。

## ログイン（認証ゲート）

アプリは `app/AuthGate.tsx` で保護されます。

- **デモ（Supabase未接続時）**：運営用 `honbu2026` ／ 代理店用 `agent2026` のパスワードで入場。
  申込フォーム `/apply` など公開ページはログイン不要。
- **本番（Supabase接続時）**：メール＋パスワードのログイン＋RLS（ロール別アクセス制御）に自動で切替。

## 本番リリース構成（納品・退職サポートと同方式）

Supabase（DB・認証・権限）＋ Vercel（画面）。未接続の間はデモ（インメモリ）で動作します。

- `supabase/schema.sql` … 本番DBスキーマ（profiles/agents/members/cases/leads/reward_payouts/audit_log）
- `supabase/rls.sql` … 行レベル権限（運営=全権／代理店=自分の分のみ／ルビー=紹介先の実績のみ・会員個人情報は不可）
- `supabase/DESIGN.md` … 本番リリース設計書（構成・権限マトリクス・進め方）
- `supabase/MIGRATION_MAP.md` … 管理スプレッドシート各タブ → テーブルの移行対応
- `lib/supabase.ts` … 接続クライアント／`.env.local` に URL・anon キーを設定すると本番モード

進め方：**Phase 0（済＝上記一式）→ Phase 1 本部がSupabaseプロジェクト作成 → Phase 2 接続・認証・権限 → Phase 3 CSV移行 → Phase 4 公開**。
本部にお願いするのは Supabaseアカウント作成（無料枠可）から。詳細は `supabase/DESIGN.md`。

## 画面構成

- `/` トップ（本店 / 代理店 / 登録 / 申込 / ログインの入口）
- `/login` ログイン（二段階認証のUIモック＋権限設計サマリ）
- `/apply?ref=<紹介コード>` 見込み客の簡易申込フォーム（代理店の紹介URL/QRから）
- 本店 管理側 `/admin`
  - ダッシュボード（KPI・ランク別・ランキング）
  - 見込み・申込（トスアップ／申込→会員化）
  - 会員管理（会員の登録・解約／アクティブ数の源泉）
  - 実績入力（アクティブ数の確認・案件登録・スプレッドシート反映）
  - 案件管理（給付・税務法務のステータス／付与pt／ショット報酬）
  - 報酬支払管理（本人報酬・ショット報酬・ルビー紹介報酬の振込）
  - 組織・代理店管理（ランク判定・一覧・新規登録）
  - 操作ログ（監査履歴：誰が・いつ・何を）
- 代理店側 `/agent`（ホーム / ランキング / 報酬 / マイページ〈紹介URL・QR・申込状況〉）
- `/join` 代理店 新規登録フォーム、`/privacy`・`/tokushoho`

## ポイント制度（共有画像に基づく実装）

- 個人代理店ランク（毎月1日に保有ptで判定・昇格/降格あり）
  - シルバー：0〜24,999pt／アクティブユーザー1名 **500pt**
  - ゴールド：25,000〜199,999pt／1名 **1,000pt**
  - プラチナ：200,000pt〜／1名 **1,500pt**
- 給付サポート成約：既定 **60,000pt** + ショット報酬あり（2026-08 本部確定・旧80,000pt）
- 税務・法務案件：**ポイントのみ**（既定 30,000pt・ショット報酬なし）
- 付与ポイントは **案件ごとに変動可**（本部確定 2026-08）。上記は既定値で、登録・案件管理で上書き可能
- 法人代理店（ルビー・招待制）：ランキング／ランク判定 **対象外**
  - 紹介先の月間ptの **50%** を報酬（お金）
  - 紹介先の月間ptの **10%** を加算pt（ランキング・ランク判定のみ）
  - 個人代理店としての報酬も受け取れる
- **ポイント ≠ 報酬**（ポイントはランキング・ランク判定用、報酬はお金として別管理）

ルールは `lib/config.ts` に集約。変更はこのファイルで完結します。

## 本店確認の状況（2026-08-05 時点）

**確定・反映済み**
1. 給付サポート成約のpt → **60,000pt に確定・反映済み**。
2. 付与ポイントを **案件ごとに変動可** に変更 → 実装済み（既定：給付60,000 / 税務法務30,000、上書き可）。
3. 「ポイント≠報酬」の表示文言 → **本部OK・確定**。
4. **ルビー報酬** → 制度マスタ確定：「紹介代理店の**アクティブユーザーptのみ × 50%**」（案件pt・給付ショット報酬は対象外）に実装済み。
5. **管理基盤 = Googleスプレッドシート**／**アプリ入力→シート反映** → Apps Script方式で実装済み（下記「スプレッドシート連携」。本番URL設定待ち）。

6. **本人報酬** → 確定：「**アクティブユーザーpt × 1円**」（ランク単価 🥈500/🥇1,000/💎1,500円/人。税務法務pt・紹介ptは対象外）に実装済み。今月報酬 = 本人報酬＋給付ショット＋ルビー報酬。
7. **会員（アクティブユーザー）を1名ずつ登録・解約** → 「会員管理」画面を追加。有効会員数からアクティブ数・本人報酬を自動算出。会員はシート「ユーザー・アクティブ会員管理」タブへ反映。

8. **権限・セキュリティ設計** → 実装済み（ロール別の閲覧範囲＋操作ログ）：
   - 代理店＝自分に紐づくユーザー/案件/pt/報酬のみ
   - ルビー＝紹介先代理店の実績のみ（配下ユーザーの個人情報は不可・ID/代理店名のみ）
   - 運営管理者＝全データ閲覧・編集、全変更を操作ログに記録（誰が/いつ/何を）
   - ※本番は認証＋サーバー側アクセス制御（RLS）で強制。プロトタイプは挙動確認用。
9. **会員登録フロー（トスアップ）** → 実装済み：
   代理店の紹介URL/QR → 見込み客が簡易フォームで申込 → 運営が「会員化」→ アクティブ会員として
   紹介元へ自動紐付け → アクティブ数・pt・本人報酬へ自動反映。将来の自動化（決済連携・OCR等）は段階的に。

**要確定（保留中）**
10. 代理店の契約取得フローの細部・自動化の優先順位（通知連携・決済連携・OCR等）→ 運用開始後に精緻化。

## Googleスプレッドシート連携（アプリ入力 → シート反映）

対象シート（本部提供）の各タブに、アプリの登録内容を反映します。バックエンド不要の
**Google Apps Script（Webアプリ）** 方式です。

**セットアップ手順**
1. 対象スプレッドシートを開く → 拡張機能 → Apps Script
2. `google-apps-script/Code.gs` の内容を貼り付けて保存
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」（実行＝自分／アクセス＝リンクを知っている全員）
4. 発行された `/exec` URL をコピー
5. プロジェクト直下に `.env.local` を作成し、次を記入（`.env.local.example` 参照）：
   ```
   NEXT_PUBLIC_SHEET_WEBAPP_URL=https://script.google.com/macros/s/.../exec
   ```
6. `npm run dev` を再起動 → 本店「実績入力」の接続状態が「接続済み」になります

**反映される内容**
- 案件の登録（実績入力）→「進行中案件・完了案件管理」タブに追記
- 代理店・ルビーの登録（組織・代理店管理／登録フォーム）→「代理店マスタ」タブにID一致で更新/追記
- アクティブ数などの一括反映 →「実績入力」の【スプレッドシートへ反映】ボタン（代理店マスタをID一致で更新）

URL未設定でもアプリは通常どおり動作します（反映のみ無効）。

## 技術

Next.js 15（App Router）＋ React 19 ＋ TypeScript。バックエンドなしのインメモリ・ストア
（`lib/store.tsx`）で、本店の操作が代理店画面へ即時反映されます。本番はここをスプレッドシート
双方向同期／DB に置き換えます。
