# 本番リリース設計書（Phase 0）— X-LABO 代理店管理アプリ

構成：**Supabase（DB・認証・権限）＋ Vercel（画面）／東京リージョン**

現状は「インメモリ試作」（データが保存されない）。本番は Supabase の実データベースに置き換え、
ログイン・権限（RLS）・操作ログ・実データ移行（本部の管理スプレッドシート）を行う。
※未接続の間は従来どおりデモ（インメモリ）で動作します（`.env.local` 未設定時）。

---

## 1. 全体構成

```
[利用者のブラウザ]
      │
[Vercel] Next.js（画面）  ──►  [Supabase]
                                 ├ Auth（メール＋パスワード）
                                 ├ Postgres（実データ）※東京リージョン
                                 ├ RLS（行レベル権限：運営 / 代理店 / ルビー）
                                 └ 操作ログ（audit_log）
```

- **フロント**：現行 Next.js を流用。データ取得元をインメモリ → Supabase に差し替え（`lib/store.tsx` に読込を実装済み）。
- **バックエンド**：Supabase（DB＋認証＋権限）。別途サーバー不要。

## 3. 権限マトリクス（`rls.sql`）— 本部指定 #8

| 操作 | admin（運営管理者） | agency（個人代理店） | ruby（法人代理店） |
|---|---|---|---|
| 全データ閲覧・編集 | ✅ | ✗ | ✗ |
| 自分のユーザー/案件/pt/報酬 | ✅ | ✅（自分の分のみ） | ✅（自分の分のみ） |
| 紹介先代理店の**実績**（人数/pt/報酬の数字） | ✅ | ― | ✅（閲覧のみ） |
| 紹介先代理店の**ユーザー個人情報** | ✅ | ― | **不可**（ID・代理店名のみ） |
| 操作ログ | ✅ 全閲覧 | ✗ | ✗ |

- ルビーは代理店画面で**紹介先の実績のみ**（`agents_view` 経由で氏名・連絡先・口座はマスク、集計数値は表示）。
- 会員（`members`）は「担当代理店本人＋運営」のみ閲覧可。ルビーは紹介先の会員個票を閲覧不可。
- すべての変更（案件登録・会員化・解約・ランク変更・報酬振込 等）を `audit_log` に記録。
- 二段階認証は将来オプション（必要なら運営管理者のみ必須に）。

## 4. データ移行 → 【方針変更・2026-08-25合意】アプリ上で直接一元管理

既存の管理データが無く運用も未開始のため、**CSVによるデータ移行は行わない**。
本番稼働後は、報酬・支払い・組織・代理店・会員・案件を**アプリ上で直接入力・一元管理**する
（アプリ＝正データ／system of record）。

- スプレッドシートは必須ではない（`google-apps-script/` の反映機能は任意のミラー用途）。
- `MIGRATION_MAP.md` は「将来まとめて取り込む場合の対応表」として参考保管。
- ※アプリが正データになるため、**書込みのSupabase永続化（Phase 2）が本番の前提**になる。

## 5. 会員登録フロー（トスアップ・#9）

代理店の専用紹介URL/QR（`/apply?ref=<紹介コード>`）→ 見込み客が簡易フォーム申込（`leads`）→
運営が登録・決済案内 →「会員化」で `members` に登録し紹介元へ自動紐付け → アクティブ数・pt・本人報酬へ反映。
将来の自動化（決済連携・通知・契約書OCR）は段階的に追加。

## 7. 進め方

1. **（済）Phase 0**：スキーマ `schema.sql`・権限 `rls.sql`・本設計書・アプリ側の接続実装
2. **Phase 1**：本部がSupabaseプロジェクト作成 → `schema.sql`→`rls.sql` を実行してDB構築
3. **Phase 2**：画面をSupabaseに接続（`.env.local`）、認証・3権限・**書込みのDB永続化**を有効化（＝アプリで直接一元管理の前提）
4. **Phase 3**：GitHub リポジトリ整備＋Vercel公開。運用担当（社内）が Claude Code + GitHub で修正・運用
5. **Phase 4**：操作ログ・メール・テスト → 本番運用開始

※ CSV移行は行わない（既存データなし・アプリで直接管理）。Phase 1 に進むには Supabaseアカウントの用意（無料枠）だけお願いします。
